# 요구사항 명세서 

## 1. 개요

- **목적**: 사용자가 웹에서 모델과 프롬프트를 입력하면, 프롬프트를 번역 후 이미지 또는 영상을 생성하여 파일로 반환하는 AI 생성 서버 구현
- **특징**: 번역 및 이미지/비디오 생성 모델을 파이프라인 풀로 관리하며, 모든 처리는 동기(순차) 방식으로 동작


## 2. 주요 기능 및 흐름

- **모델 및 프롬프트 입력**: 웹 UI에서 모델과 프롬프트 입력
- **프롬프트 번역**: 한글 프롬프트를 영어로 번역 (facebook/nllb-200-distilled-1.3B)
- **이미지/비디오 생성**: Stable Diffusion 계열 및 Wan 계열 모델로 생성
- **결과 반환**: 생성된 파일을 `outputs/` 폴더에 저장하고, 경로 및 메시지 반환
- **파이프라인 풀**: 각 모델별로 최대 1개 인스턴스만 관리, 요청은 순차적으로 처리


## 3. API 엔드포인트

| 엔드포인트 | 메서드 | 설명 |
| :-- | :-- | :-- |
| `/image-models` | GET | 사용 가능한 이미지 생성 모델 목록 반환 |
| `/video-models` | GET | 사용 가능한 비디오 생성 모델 목록 반환 |
| `/generate-image` | POST | 이미지 생성 요청 (모델명, 프롬프트 입력) |
| `/generate-video` | POST | 비디오 생성 요청 (모델명, 프롬프트 입력) |
| `/download/{filename}` | GET | 생성된 이미지/비디오 파일 다운로드 |

## 4. 입력 및 출력 명세

### 이미지 생성 요청

- **입력**
    - `model_name`: 이미지 생성 모델명 (`SD_1.5`, `SD_3.5M`)
    - `prompt`: 생성 프롬프트 (한글/영어)
- **출력**
    - `message`: 처리 결과 (`OK` 또는 `ERROR`)
    - `image_path`: 생성 파일 경로 (`outputs/` 내 파일명)
    - `task_id`: 요청 고유 ID


### 비디오 생성 요청

- **입력**
    - `model_name`: 비디오 생성 모델명 (`Wan_1.3B`)
    - `prompt`: 생성 프롬프트 (한글/영어)
- **출력**
    - `message`: 처리 결과 (`OK` 또는 `ERROR`)
    - `image_path`: 생성 파일 경로 (`outputs/` 내 파일명)
    - `task_id`: 요청 고유 ID

## 6. 시스템 구성 및 파일 역할

| 파일명 | 주요 역할 |
| :-- | :-- |
| `shared.py` | 모델 캐시, 번역 모델/토크나이저, 파이프라인 풀(Queue) 및 락 관리 |
| `Translate.py` | 번역 모델 초기화 및 프롬프트 번역 함수 제공 |
| `ModelLoad.py` | 모델 로딩, 파이프라인 풀 관리, GPU 메모리 최적화, 파이프라인 획득/반환 함수 제공 |
| `Text_to_Image_Multi.py` | FastAPI 서버, API 엔드포인트 구현, 요청 처리 및 결과 반환 |

## 7. 주요 처리 흐름

1. **서버 시작 시**
    - 번역 모델 및 각 생성 모델을 1개 인스턴스로 로드하여 파이프라인 풀(Queue)에 저장
2. **이미지/비디오 생성 요청**
    - 프롬프트를 번역
    - 파이프라인 풀에서 해당 모델의 인스턴스를 획득
    - 생성 결과를 파일로 저장
    - 파이프라인 인스턴스를 다시 풀에 반환
    - 결과 메시지와 파일 경로 반환
3. **파일 다운로드**
    - `/download/{filename}` 엔드포인트를 통해 파일 반환

## 8. 동작 및 리소스 관리

- **동기(순차) 처리**: 모든 요청은 한 번에 하나씩 처리됨
- **파이프라인 풀**: 각 모델별로 최대 1개 인스턴스만 Queue로 관리, 동시 요청은 대기
- **모델 캐싱**: 최초 1회만 로드, 이후 재사용
- **GPU/CPU 최적화**: GPU 메모리 상황에 따라 최적화 옵션 적용, 번역 모델은 CPU에서만 동작

## 10. 기타 구현 상세

- 프롬프트 번역은 CPU에서 실행
- 이미지/비디오 생성 결과는 `outputs/` 폴더에 저장
- 생성 파라미터(해상도, 스텝 등)는 코드 내 기본값 사용
- 에러 발생 시 메시지와 태스크 ID 반환
- 동작은 동기 방식
- 파이프라인 풀은 구조적 일관성 및 추후 확장성 고려
- 코드 내 모델별 지원 여부, 입력 파라미터 등은 하드코딩되어 있음
