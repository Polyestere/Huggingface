
# 요구사항 명세서

## 1. 개요

- **목적**: AI 기반 번역 및 이미지 생성 모델을 활용하여, 사용자가 웹사이트를 통해 프롬프트와 모델을 선택하면 이미지를 생성하고 결과를 반환하는 서비스 구현
- **특징**: 번역 모델과 이미지 생성 모델을 효율적으로 관리하며, 동시 요청 처리와 모델 캐싱을 통해 성능을 최적화


## 2. 핵심 기능 흐름

- **모델 및 프롬프트 입력**: 사용자가 웹 UI에서 모델과 프롬프트를 입력
- **번역 처리**: 한글 프롬프트를 영어로 번역 (facebook/nllb-200-distilled-1.3B)
- **이미지 생성**: Stable Diffusion 계열 모델로 이미지 생성
- **결과 반환**: 생성된 이미지를 서버에 저장하고, 성공 메시지와 이미지 경로를 반환
- **동시 요청 처리**: 모델별 락과 비동기 처리를 통해 여러 사용자의 동시 요청을 안정적으로 처리


## 3. 상세 요구사항

1. **GET /models**
    - 사용 가능한 모델 목록과 각 모델별 예상 이미지 생성 시간 및 모델 링크 반환
2. **POST /generate-image**
    - 입력: 모델명, 프롬프트, 해상도 등
    - 처리: 프롬프트 번역 → 모델 로딩 → 이미지 생성 → 파일 저장
    - 출력: 성공 메시지, 이미지 경로, 태스크 ID 반환
3. **GET /status**
    - 현재 활성 태스크 수, 로드된 모델 수 반환
4. **이미지 파일 반환**
    - 현재 코드에는 이미지 파일을 직접 반환하는 엔드포인트는 없음
    - 생성된 이미지는 서버의 `outputs/` 폴더에 저장되고, 경로만 반환됨

## 4. 사용 모델 및 링크

| 구분 | 모델명/경로 | 설명 |
| :-- | :-- | :-- |
| 번역 모델 | [facebook/nllb-200-distilled-1.3B](https://huggingface.co/facebook/nllb-200-distilled-1.3B) | 한글 → 영어 프롬프트 번역 |
| 이미지 생성 | [stabilityai/stable-diffusion-3.5-medium](https://huggingface.co/stabilityai/stable-diffusion-3.5-medium) | 텍스트 기반 이미지 생성 |
|  | [stable-diffusion-v1-5](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5) | 텍스트 기반 이미지 생성 |

## 5. 시스템 구성 및 주요 모듈

| 파일명 | 주요 역할 및 기능 요약 |
| :-- | :-- |
| `shared.py` | 모델 캐시(`cached_models`), 번역 모델 및 토크나이저 전역 객체 관리 |
| `Translate.py` | 번역 모델 초기화 및 프롬프트 번역 함수 제공 (facebook/nllb-200-distilled-1.3B) |
| `ModelLoad.py` | Stable Diffusion 계열 모델 로딩 및 캐싱, GPU 메모리 상황에 따른 최적화 적용 |
| `Text_to_Image_Multi.py` | FastAPI 서버, 이미지 생성 요청 비동기 처리, 번역 및 모델 로딩 연동, 동시성 제어 |

## 6. API 엔드포인트

- `GET /models`: 사용 가능한 모델, 예상 생성 시간, 모델 링크 반환
- `POST /generate-image`: 이미지 생성 요청 (모델명, 프롬프트, 해상도 등)
- `GET /status`: 현재 활성 태스크 및 모델 로딩 현황

## 8. 동시 요청 및 리소스 관리

- **모델별 락**: 동일 모델에 대한 동시 요청 시 `asyncio.Lock`을 사용하여 처리
- **모델 캐싱**: `shared.cached_models`를 통해 중복 로딩 방지 및 성능 최적화
- **비동기 처리**: FastAPI와 Python의 비동기 기능을 활용하여 여러 요청을 처리
